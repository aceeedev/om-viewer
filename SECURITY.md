# Security Policy

## Reporting a vulnerability

Please report security problems privately through [GitHub's vulnerability reporting](https://github.com/aceeedev/om-viewer/security/advisories/new), not in a public issue. Include what you found and how to reproduce it.

Only the live site at [omviewer.com](https://omviewer.com) and the `main` branch are supported. This is a personal project, so replies and fixes are best effort.

## Scope

The most useful reports let a photo or its metadata leave the browser, get script into the page, or get around the site's security headers.

Not security issues: a photo that crashes or freezes the viewer ([open an issue](https://github.com/aceeedev/om-viewer/issues) instead), problems with other sites such as photo hosts, Vercel or GitHub, and scanner results with no working attack behind them.
